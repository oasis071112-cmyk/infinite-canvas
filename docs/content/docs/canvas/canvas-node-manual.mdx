# Canvas Node Guide

## Text nodes

Text nodes store prompts, drafts, descriptions, and AI-generated text. Double-click the content or select **Edit Text** to edit it.

- An empty node generates text into itself.
- Editing existing content creates a connected result node and preserves the original.
- Use `@` to reference connected images, text, or audio. Image references render as thumbnails and are numbered automatically when sent.
- A model selected on the node does not change the global default.

## Image nodes

- Upload, drop, or insert images from **My Assets**.
- Generate into an empty image node or reuse an existing image as a reference.
- Keep multiple results in an image group and select the primary image.
- Record prompt, generation type, model, size, quality, count, and references for retries.
- Replace, download, save, crop, mask-edit, split, upscale, super-resolve, or generate alternate angles.

## Audio nodes

- Upload or drop MP3/WAV files.
- Play audio through the native player.
- Replace or download the current audio.

## Generation configuration nodes

- Switch between image and text modes.
- Read connected text, image, and audio inputs and select references with `@`.
- Choose the matching model and parameters, then start or stop generation.

## Recommended workflow

1. Create a text node with the initial idea.
2. Ask AI to refine the prompt in the panel below it.
3. Compare the connected rewritten node with the original.
4. Select **Generate Image** on the chosen text node.
5. Adjust parameters or regenerate from the connected configuration node.
