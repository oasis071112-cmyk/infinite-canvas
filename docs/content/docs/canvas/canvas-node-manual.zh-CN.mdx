# 画布节点操作手册

## 文本节点

文本节点用于保存提示词、草稿、说明文案和 AI 生成的文字结果。双击内容区域或选择“编辑文字”即可修改内容，工具栏还可以调整字号。

选中文本节点后打开下方对话框：

- 空节点会把生成结果写回当前节点。
- 修改已有内容会在右侧创建并连接新的文本节点，保留原文用于对比。
- 输入框支持 `@` 引用已连接的图片、文本和音频；图片引用会显示真实缩略图并在发送时自动编号。
- 当前节点选择的模型不会修改其他节点或全局默认模型。

## 图片节点

- 上传、拖入或从“我的素材”插入图片。
- 空图片节点可以直接生成到当前节点；已有图片会作为参考图继续生成。
- 多图生成会保存为图片组，支持展开结果和设置主图。
- 生成结果会记录提示词、生成类型、模型、尺寸、质量、数量和参考图，便于重试。
- 支持替换、下载、保存素材、裁剪、蒙版编辑、切图、放大、超分和多角度生成。

## 音频节点

- 上传或拖入本地 MP3/WAV 音频，也可以通过音频模型生成。
- 节点内使用原生播放器播放音频。
- 支持替换和下载音频。
- 生成配置节点的音频模式读取上游文本作为生成内容，并使用当前音频模型与声音参数。

## 生成配置节点

- 支持图片、文本和音频三种生成模式。
- 读取连接的上游文本、图片和音频资源，并通过 `@` 选择要使用的输入。
- 可在节点内选择对应模型和生成参数，然后开始或停止生成。

## 推荐流程

1. 新建文本节点，写入图片创作想法。
2. 打开节点下方对话框，让 AI 优化或扩写提示词。
3. 对比新旧文本节点并确认最终内容。
4. 点击“生图”创建并连接生成配置节点。
5. 在生成配置节点中调整图片参数并继续生成。
