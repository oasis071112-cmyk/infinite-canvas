# Security Reports

Do not publish exploit details, private API keys, screenshots with sensitive data, or real user data in a public issue.

Use GitHub private vulnerability reporting or a Security Advisory. If unavailable, email [1844025705@qq.com](mailto:1844025705@qq.com) with `[infinite-canvas security]` in the subject.

Include the affected version or commit, reproduction steps, impact and prerequisites, redacted logs or proof of concept, and whether browser storage, anonymous sessions, encrypted provider settings, restricted AI proxying, or network requests are involved.

The project prioritizes vulnerabilities caused by repository code or defaults, including XSS, anonymous-session isolation failures, decrypted-key exposure, SSRF bypasses, unsafe imports or exports, access-control errors, and exploitable supply-chain issues. Problems confined to third-party services, leaked user credentials, recommendations without an exploit path, phishing, and account recovery are normally outside scope.

Remote canvas plugins run in the page and can access browser-local canvas and media data or invoke actions available to the active anonymous session. They do not receive decrypted provider keys. Install only trusted plugins.
