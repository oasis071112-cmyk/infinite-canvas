# 漏洞提交

请不要在公开 Issue 中发布漏洞细节、私密 API Key、包含敏感信息的截图或真实用户数据。

优先使用 GitHub 私密漏洞报告或 Security Advisory；若仓库没有对应入口，请发送邮件至 [1844025705@qq.com](mailto:1844025705@qq.com)，标题包含 `[infinite-canvas security]`。

请提供受影响的版本或提交、复现步骤、影响与前置条件、脱敏后的日志或 PoC，并说明是否涉及浏览器存储、匿名会话、加密渠道配置、受限 AI 代理或网络请求。

项目会优先处理由本仓库代码或默认配置导致的 XSS、匿名会话隔离失败、解密 Key 泄露、SSRF 绕过、不安全导入导出、权限错误和可利用的供应链问题。仅存在于第三方服务、用户自行泄露凭据、没有实际利用路径的建议、社工钓鱼或账号找回通常不属于本项目范围。

远程画布插件运行在网页中，可访问浏览器本地画布和媒体数据，也可调用当前匿名会话已有的功能，但不会获得解密后的渠道 Key。请只安装可信插件。
