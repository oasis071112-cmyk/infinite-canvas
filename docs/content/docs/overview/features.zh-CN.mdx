# 功能介绍

本文档记录 IonAiLabs无限画布 当前已经实现的主要功能。

## 画布项目

- 创建、重命名、删除、批量选择、导入和导出多个画布项目。
- 在浏览器本地保存节点、连线、视口和背景。
- 可选使用 WebDAV 同步画布、素材、生图记录和本地媒体文件。

## IonAiLabs无限画布

- 拖动画布、滚轮缩放、缩放滑杆、重置视图和小地图定位。
- 点阵、网格线、空白三种背景以及浅色、深色主题。
- 框选、多选、全选、复制粘贴、撤销重做和选中内容导出。
- 节点连线及当前节点上下游关系高亮。

## 节点与生成流程

当前内置文本、图片、音频、生成配置和分组节点：

- 文本节点保存提示词、说明文案和 AI 文字结果。
- 图片节点展示上传、生成或素材库中的图片，默认保持原始比例。
- 音频节点展示上传的音频，并提供原生播放、替换与下载。
- 生成配置节点汇总上游文本、图片和音频，统一配置对应模型与生成参数。
- 分组节点用于组织画布中的相关内容。

节点支持移动、缩放、连接、复制、粘贴、删除和信息查看。图片批量生成会以图片组保存全部结果，并支持设置主图。

## AI 生成

前端使用浏览器本地配置的 Base URL、API Key 和模型，直接请求兼容接口：

- `/v1/images/generations`：文生图。
- `/v1/images/edits`：图生图和参考图编辑。
- `/v1/responses`：文本问答和带图问答。
- `/v1/models`：读取模型列表。

可配置多个渠道，并为模型指定生图或文本能力。支持图片质量、比例、透明背景、生成数量、文本推理强度以及自定义调用脚本。火山方舟协议继续支持生图请求。

节点下方对话框和组装提示词输入框支持 `@` 引用已连接的图片、文本和音频资源；图片引用会直接显示缩略图，发送时按当前连接自动编号。

## 节点插件系统

- 通过 URL 安装、启用、更新和卸载远程节点插件。
- 从项目注册表读取官方插件并一键安装。
- TypeScript 插件 SDK 支持自定义节点、工具栏、面板和文本、图片生成能力。
- 内置 Markdown、SVG、HTML、3D 全景和便利贴等示例插件。

## 提示词库与素材

- 浏览器前端直连多个公开提示词仓库，并缓存到 IndexedDB。
- 支持来源同步、搜索、标签筛选、详情查看、复制和加入素材。
- “我的素材”保存文本和图片，可搜索、筛选、导入、导出并插入画布。

## 当前限制

- 画布项目和“我的素材”保存在浏览器本地，不提供账号云同步。
- AI API Key 保存在浏览器本地，并由浏览器直接请求配置的接口，只适合个人或可信环境使用。
- Docker 静态资源路径仍需要更广泛的生产部署验证。
- 画布更适合桌面端使用，移动端触控体验尚未系统完善。
