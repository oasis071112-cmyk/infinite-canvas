# IonAiLabs无限画布

IonAiLabs无限画布将可视化画布、AI 生图与图片编辑、文本生成、本地音频素材、提示词库和素材沉淀放在同一个工作台中。

## 画布与本地数据

- 支持多个画布项目，以及节点拖拽、缩放、连线、撤销重做和导入导出。
- 画布项目、导入图片、生成图片、音频、素材和完整生成历史均保存在浏览器 IndexedDB。
- 服务器不保存画布或媒体文件。清除匿名会话 Cookie 不会删除本地画布，但浏览器会获得新的服务端渠道配置空间。

## 匿名 AI 配置

- 无需注册，不保存用户名、邮箱或密码。
- 后端首次访问时创建随机匿名会话，通过 `HttpOnly + Secure + SameSite=Strict` Cookie 保存，并按最后访问时间滚动一年。
- 每个匿名会话可以保存多个公网 HTTPS OpenAI 兼容中转站。
- API Key 通过 HTTPS 提交，使用 AES-256-GCM 加密保存，不会返回浏览器，也不会进入配置导出文件。
- 可从 `/v1/models` 自动读取模型；中转站未实现该接口时，可手动添加并标记为图片或文本模型。

## 受限的同域 AI 网关

浏览器只访问同域 `/api`，Node 服务根据 `providerId` 解析中转站，只开放以下上游能力：

- OpenAI 兼容 Responses
- 图片生成
- 图片编辑
- 模型列表

系统不提供任意路径代理，不支持原生 Gemini、原生火山方舟、自定义请求脚本或 WebDAV。中转站地址必须是公网 HTTPS；每次请求前都会重新校验，并拒绝重定向、私网、回环、链路本地、保留地址和云元数据地址。

## 服务端记录

SQLite 仅保存匿名会话、加密渠道配置、模型分配和最小调用摘要。调用摘要只包含模型、能力、状态、HTTP 状态、耗时、错误码和时间，不保存提示词、消息、参考图、音频、画布或生成结果，默认保留 90 天。

## 其他能力

- 提示词中心：由浏览器同步支持的公开仓库并缓存到 IndexedDB。
- 本地图片与音频素材管理。
- 远程画布节点插件：插件运行在网页中，可访问浏览器本地画布数据，但不能读取服务端解密后的渠道 Key。
