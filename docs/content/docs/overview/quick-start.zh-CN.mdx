# 快速开始

IonAiLabs无限画布现在需要同时运行 Vite/React 前端与 Node API，浏览器不会再直接请求模型中转站。

## 本地 Docker 预览

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose -f docker-compose.local.yml up --build
```

打开 `http://localhost:3000`。本地 Compose 使用仅供开发的主密钥和非安全 Cookie，不可直接用于公网服务器。

## 生产环境准备

```bash
cp .env.example .env
openssl rand -base64 32
```

将生成值写入 `API_KEY_MASTER_KEY`，把 `APP_ORIGIN` 改为最终 HTTPS 域名，并设置 `COOKIE_SECURE=true`，然后启动：

```bash
mkdir -p data
sudo chown -R 1000:1000 data
chmod 700 data
docker compose up -d --build
```

公网访问前还需配置宿主机 Nginx 和 TLS，并且只让 Nginx 暴露公网端口。详见 [Docker 部署](/zh-CN/docs/overview/docker)。

## 配置第一个中转站

打开配置，通过客服提示后添加公网 HTTPS 的 OpenAI 兼容 Base URL 与 API Key。可从 `/v1/models` 拉取模型；如果中转站没有模型列表，则手动添加图片或文本模型。

画布和媒体继续保存在浏览器 IndexedDB；中转站配置按匿名 Cookie 隔离，并加密保存在服务器 SQLite。
