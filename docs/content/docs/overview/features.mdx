# Features

## Canvas projects

- Create, rename, delete, import, export, and batch-manage canvas projects.
- Persist nodes, connections, viewport, background, and assistant sessions in the browser.
- Optionally synchronize canvases, assets, image history, and local media through WebDAV.

## IonAiLabs Infinite Canvas

- Pan, zoom, reset the view, use the minimap, and choose lines, dots, or a blank background.
- Select multiple nodes, copy and paste, undo and redo, and export the canvas or selected elements.
- Connect nodes and highlight upstream and downstream relationships.

## Nodes and generation workflows

Built-in nodes cover text, images, audio, generation configuration, and groups.

- Text nodes store prompts, copy, and AI-generated text.
- Image nodes display uploaded, generated, or saved images while preserving their original ratio by default.
- Audio nodes play uploaded or generated audio and support downloads.
- Configuration nodes combine upstream text, image, and audio inputs with the matching model settings.
- Group nodes organize related canvas content.

Batch image generation keeps all results in an image group and lets users select the primary result.

## AI generation

- Connect directly from the browser to user-provided compatible endpoints.
- Use image generation and editing, Responses-based text generation, audio speech generation, and model discovery endpoints.
- Configure multiple providers and assign image, text, or audio capabilities to each model.
- Control image quality, aspect ratio, transparent backgrounds, output count, text reasoning effort, audio voice and format, and custom invocation scripts.
- Keep Volcengine Ark image generation support.

Prompt panels support `@` references to connected images, text, and audio. Image references render as thumbnails and are renumbered automatically when sent.

## Canvas Agent

- Connect local Codex through Canvas Agent and MCP.
- Read the active canvas, selection, nodes, connections, and generation status.
- Apply structured operations and start text, image, or audio workflows.
- Use streaming conversations, history, approvals, permissions, diagnostics, and local Skills in the browser side panel.

See [Codex App Plugin](/docs/overview/codex-app-plugin) for installation and usage.

## Plugin system

Canvas plugins can contribute node types, rendering, inspectors, serialization, toolbar actions, panels, and optional text or image generation capabilities. Built-in and local plugins are managed through the canvas UI.

## Prompts and assets

- Synchronize supported public prompt repositories and add custom standard JSON sources.
- Search enabled sources, filter by tags, inspect prompt details, copy prompts, and insert them into the canvas.
- Store reusable text and image assets in the browser.

## Current limitations

- The project is frontend-first and does not provide built-in cloud accounts or cloud storage.
- API keys remain in browser storage and requests are sent directly to configured providers.
- Production Docker static-resource paths still require broader deployment verification.
