# IonAiLabs Infinite Canvas

IonAiLabs Infinite Canvas combines visual canvas workflows, image generation and editing, text generation, local audio assets, prompt libraries, and reusable materials in one workspace.

## Canvas and local data

- Create multiple canvas projects with draggable, resizable, connectable nodes.
- Keep canvas projects, imported images, generated images, audio files, assets, and complete generation history in browser IndexedDB.
- Import and export canvas data locally. The server does not store canvas or media files.
- Clearing the anonymous-session cookie does not remove local canvas data, but the browser will receive a new server-side provider scope.

## Anonymous AI configuration

- No registration, username, email address, or password is required.
- The backend creates a random anonymous session in an `HttpOnly`, `Secure`, `SameSite=Strict` cookie and rolls its one-year expiry on activity.
- Each session may store multiple public HTTPS OpenAI-compatible providers.
- Provider keys are submitted over HTTPS, encrypted with AES-256-GCM, and never returned to the browser or included in exports.
- Models can be refreshed from `/v1/models` or added manually and marked for image or text use.

## Restricted same-origin AI gateway

The browser calls only same-origin `/api` endpoints. The Node service resolves the selected provider and supports these upstream operations:

- OpenAI-compatible Responses
- Image generations
- Image edits
- Model listing

There is no arbitrary-path proxy. Native Gemini, native Volcengine Ark, custom request scripts, and WebDAV are not supported. Provider URLs must use public HTTPS and are revalidated before every request; redirects and private, loopback, link-local, reserved, and cloud-metadata targets are rejected.

## Server-side records

SQLite stores anonymous sessions, encrypted provider settings, model assignments, and minimal call summaries. Summaries contain model, capability, status, HTTP status, duration, error code, and time only. They do not contain prompts, messages, reference images, audio, canvas data, or generated results, and expire after 90 days by default.

## Other capabilities

- Prompt Center with browser-side synchronization and IndexedDB caching for supported public repositories.
- Local image and audio asset management.
- Remote canvas-node plugins. Plugins run in the page and may access browser-local canvas data, but they cannot read decrypted provider keys.
