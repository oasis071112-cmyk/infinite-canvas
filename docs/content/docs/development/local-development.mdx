# Local Development

Use Node.js 22. The frontend and backend have separate dependencies.

## Recommended preview

```bash
docker compose -f docker-compose.local.yml up --build
```

Open `http://localhost:3000`.

## Run from source

Install dependencies in both workspaces:

```bash
cd server
npm install
cd ../web
bun install
```

Set these development environment variables for the API before starting it:

```text
API_KEY_MASTER_KEY=<32-byte Base64 value>
APP_ORIGIN=http://localhost:3000
COOKIE_SECURE=false
DATABASE_PATH=./data/ionailabs-canvas.sqlite
```

Run `npm run dev` in `server/`, then `bun run dev` in `web/`. Vite proxies `/api` to `http://localhost:4000`.

Do not reuse the development master key in production. Source development still stores canvas and media in the browser; only anonymous sessions, encrypted providers, model assignments, and call summaries are written to local SQLite.
