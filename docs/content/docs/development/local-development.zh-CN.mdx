# 本地开发

请使用 Node.js 22，前端与后端分别安装依赖。

## 推荐预览方式

```bash
docker compose -f docker-compose.local.yml up --build
```

打开 `http://localhost:3000`。

## 源码运行

分别安装依赖：

```bash
cd server
npm install
cd ../web
bun install
```

启动 API 前设置以下开发环境变量：

```text
API_KEY_MASTER_KEY=<32 字节 Base64 值>
APP_ORIGIN=http://localhost:3000
COOKIE_SECURE=false
DATABASE_PATH=./data/ionailabs-canvas.sqlite
```

先在 `server/` 执行 `npm run dev`，再在 `web/` 执行 `bun run dev`。Vite 会把 `/api` 转发到 `http://localhost:4000`。

不要在生产环境复用开发主密钥。源码开发时，画布和媒体仍保存在浏览器；只有匿名会话、加密渠道、模型分配和调用摘要会写入本地 SQLite。
